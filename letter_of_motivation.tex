\noindent\textbf{Systems Engineering \& Independent Implementations} \\
Rather than consuming off-the-shelf wrappers, my work centers on engineering first-principles systems that tackle real-world constraints:
\begin{itemize}[leftmargin=0.18in, itemsep=0.5pt, topsep=0.5pt]
  \item \textbf{Decoupled Document AI \& Edge RAG (\textit{DocMind})}: Tackling data confidentiality and cloud latency in corporate document search, I designed an offline RAG platform utilizing Docling layout analysis and ChromaDB vector embeddings. To balance privacy with complex multi-hop reasoning, I built an adaptive router that processes routine inference on local quantized models (Ollama) while escalating high-entropy queries to external endpoints, reducing inferencing overhead by $\sim$60\% with zero data egress.
  \item \textbf{Adversarial AI Security \& Guardrail Engineering (\textit{HackMentor AI})}: As AI/ML Associate at DEVS (REC), I co-engineered an automated evaluation workspace serving 15+ judging panels. I researched and deployed multi-layered prompt injection mitigations—combining lexical token sanitization, structural boundary isolation, and system prompt anchoring—successfully repelling 30+ simulated direct and indirect injection vectors without degrading evaluation fidelity.
  \item \textbf{Digital Forensics \& Graph Threat Intelligence (\textit{MailShield-AI})}: Architected an 8-stage email security forensic system under national Smart India Hackathon (SIH 2026) guidelines, combining RFC 5322 header parsing, threat scoring heuristics, and graph correlation across IOCs.
  \item \textbf{Acoustic Emotion Classification (\textit{Risonanza})}: Developed a low-latency speech emotion recognition service using Librosa MFCC and Chroma spectral extraction paired with Scikit-learn classifiers, achieving $\sim$85\% test accuracy with sub-300ms audio inference.
\end{itemize}
